ClassPredictor

Academic planning, built around the topics that depend on each other.

I built ClassPredictor to help students identify the foundations that need attention before they move to more advanced topics.

A directed prerequisite graph connects those topics. Risk scores, a prioritization matrix, and a phased roadmap turn the dependencies into a practical preparation plan.

Built independently with React, Vite, D3.js, and Firebase. The implementation is public.

002 — Live project

SYNAPSE

A reflection flow, an AI plan, and a reason to check in tomorrow.

I built SYNAPSE to connect habit reflection with daily follow-through. A five-step flow collects the pattern before an AI-generated plan gives it structure.

Daily check-ins, streak resets, setback responses, and milestone drops support the ongoing experience. Firebase authentication and server-side verification protect the AI request path.

Now live, with Groq and LLaMA 3.3 70B powering the planning flow.

003 — Independent build

Verdikt

One terminal for news scattered across Indian market feeds.

I built Verdikt to collect news from five market publishers, deduplicate repeated stories, and organize AI-generated impact assessments.

The pipeline combines SHA-256 hashing with a Gemini multi-agent evaluation stage. API key rotation supports continued processing; the terminal supports English, Hindi, and Hinglish.

The React frontend runs on Vercel and the continuous ingestion backend runs on Railway.
